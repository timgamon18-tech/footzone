# FootZone — Le football partout ⚽

Prototype mobile Expo au style sombre et vert électrique.

## Fonctionnalités incluses
- Accueil avec cartes de matchs
- Filtres Tous / En direct / Favoris
- Favoris locaux
- Écran de détail avec statistiques de démonstration
- Explorer les compétitions
- Classement de démonstration
- Navigation mobile

## Lancer le projet
1. Installe Node.js sur ton ordinateur.
2. Dans le dossier du projet, lance `npm install`.
3. Lance `npx expo start`.
4. Scanne le QR code avec Expo Go ou ouvre la version web avec `npm run web`.

## Important
Les matchs, scores, horaires, statistiques et classement fournis sont fictifs et servent uniquement à tester l'interface. Ils ne sont pas des résultats en direct. Pour publier une vraie application, connecte une API football, vérifie ses conditions d'utilisation et protège la clé API côté serveur.
